# dsh-sql-formatter

> DeepSeek Harness SQL 格式化与优化插件

## 功能

- ✨ **SQL 格式化**: 自动美化 SQL 语句
- 📊 **查询分析**: 分析查询性能和复杂度
- ⚡ **优化建议**: 检测 N+1 查询、缺失索引
- 🔍 **索引建议**: 根据 schema 建议索引

## 工具

| 工具名 | 说明 |
|--------|------|
| `sql_format` | 格式化 SQL |
| `sql_analyze` | 分析查询 |
| `sql_optimize` | 优化建议 |
| `sql_indexes` | 索引建议 |
| `sql_explain` | EXPLAIN 计划 |
